Technology Stack Justification & Trade-Off Analysis

Every layer of the Campus Critique technical stack has been selected through empirical benchmark trade-offs, prioritizing deterministic correctness and sub-second performance over complex autonomous abstractions.

Layer Selected Technology Rejected Alternatives Architectural Justification
Model Access Layer Vercel AI SDK (v3.x) (generateObject + Zod) LangGraph.js, Mastra, AutoGen Zero agentic overhead. Constrains generation to typed JSON schemas. LangGraph.js trails Python updates by 4–8 weeks and introduces unnecessary state graph complexity for linear counseling stages.
Messaging Gateway Meta WhatsApp Cloud API Direct Twilio, Gupshup, Wati Direct HTTPS Graph API v20.0 with ₹0 markup. Third-party BSPs charge 15–25% markups and introduce 600–900ms added network hops without supporting custom TypeScript guardrails.
Message Queue & Debounce Upstash QStash BullMQ / Redis, AWS SQS, Cloud Tasks Serverless HTTP broker requiring zero dedicated worker infrastructure. Delivers native sliding-window 4000ms debounce and deduplication on wamid.
Relational & Vector DB Supabase PostgreSQL 16 + pgvector Pinecone, Qdrant, Chroma Single database instance hosting relational facts and HNSW vector embeddings. Eliminates dual-write consistency hazards and ₹5,000/mo vector cloud fees.
CI/CD Red-Teaming Promptfoo (GitHub Actions) DeepEval, Braintrust Node-native, fast YAML-based CI scanner running 50+ vulnerability scans (jailbreaks, prompt leaks, numeric fee baiting) on every PR.
Telemetry & Tracing Langfuse (Self-Hosted) Datadog, Arize Phoenix Native OpenTelemetry GenAI semantic conventions (gen_ai.*) running on an open-source ClickHouse container with zero vendor lock-in.
02

System Architecture & Component Decomposition

The fundamental premise of our architecture is defence in depth: the Large Language Model is the least reliable component in the system; therefore, it is granted the smallest operational scope and the maximum deterministic supervision.

Subsystem Isolation (Decision D9)

The WhatsApp bot resides in its own Git repository and Vercel project, accessing an isolated wa schema inside Supabase. Static institutional facts and approved student reviews are synced via an automated nightly read-only ETL script. If the main web platform experiences outages, the counseling service continues operations off its verified local snapshot without failure.

Critical Engineering Bottlenecks & Solutions

Building a conversational agent for high-stakes admission decisions exposes several architectural failure modes. Below is the technical resolution matrix:

# Engineering Bottleneck Failure Mode & Impact Architectural Solution Implemented
1 Meta 3-Second Webhook Timeout Serverless cold starts or multi-step LLM chains exceed 3000ms → Meta floods endpoint with retries. Immediate Edge ACK: Webhook performs HMAC check, drops event into QStash queue, and returns HTTP 200 OK within <220ms. Worker executes asynchronously.
2 Burst Multi-Message Collisions Adolescents send 3–4 rapid messages in 5 seconds → Bot fires multiple uncoordinated replies. 4000ms Sliding Window: Upstash QStash aggregates successive messages per wa_id into a single consolidated execution prompt.
3 Numeric Cutoff & Fee Hallucination LLM fabricates closing ranks or fees → Student reorganizes plans around false data. Zero Model Math Authority: Arithmetic is executed by Layer A code; facts by Layer B SQL. Rail 4 token scanner aborts any unindexed number.
4 Western Safety Guard Blindspots Off-the-shelf classifiers miss Indian academic guilt ("kis muh se ghar jau"). Decomposed 5-Boolean Classifier: Deconstructs Hinglish exam guilt into concrete flags with zero false-negative tolerance, escalating to Tele-MANAS.
5 Meta 24h Window Expiration Outbound messages sent past 24 hours of user's last inbound fail delivery. Session Window Gate: Rail 5 inspects last_inbound_at. If expired, automatically switches to pre-approved Meta Utility Templates.
6 Serverless DB Pool Exhaustion Traffic surges exhaust PostgreSQL max connections in serverless functions. Supavisor Connection Pooling: Routes database connections through transaction pooler; separates write queries from read replicas.
7 RAG Semantic Ambiguity on Numbers Vector similarity cannot evaluate numerical ranges (12,847 rank vs 13,002). Strict Segregation: Vector embeddings are strictly restricted to qualitative review prose. All cutoffs reside in SQL tables.

The Five-Rail Guardrail Engine: Code Contracts

Rail 1: Decomposed Distress Evaluation

export interface DistressEvaluation {
  hopelessness_future: boolean;      // weight: 0.10 ("kuch nahi bacha ab")
  self_harm_suicide: boolean;         // weight: 0.35 ("sab khatam karna chahta hu")
  irreparable_family_shame: boolean;  // weight: 0.20 ("papa ka sar jhuka diya")
  plan_or_method_reference: boolean;  // weight: 0.25 (concrete methods mentioned)
  feeling_of_burden: boolean;         // weight: 0.10 ("sab par bojh hu")
}

export function evaluateCrisisScore(evals: DistressEvaluation): number {
  return (
    (evals.self_harm_suicide ? 0.35 : 0) +
    (evals.plan_or_method_reference ? 0.25 : 0) +
    (evals.irreparable_family_shame ? 0.20 : 0) +
    (evals.hopelessness_future ? 0.10 : 0) +
    (evals.feeling_of_burden ? 0.10 : 0)
  );
  // Threshold >= 0.40 halts state transitions and dispatches Tele-MANAS 14416
}

Rail 2: The Mandatory Gate Invariant

export function canTransitionToNarrow(profile: StudentProfile): boolean {
  // Hard invariant: Recommendations are permanently blocked
  // until all three stress-test dimensions complete and clear.
  return (
    profile.loan_test_completed === true &&
    profile.downside_test_completed === true &&
    profile.degree_test_completed === true &&
    profile.loan_affordability_cleared === true
  );
}

Rail 4: Output Guardrail Token Scanner

export function sweepNumericClaims(candidateText: string, factBlock: ImmutableFactBlock): boolean {
  // Regex extracting all monetary figures (₹), percentages (%), LPA packages, and ranks (>3 digits)
  const regex = /(?:₹|Rs\.?)\s*[\d,.]+(?:\s*(?:Lakh|Crore|L|Cr))?|\b\d+(?:\.\d+)?\s*(?:LPA|%|percentile|rank)\b|\b\d{4,7}\b/gi;
  const extractedTokens = candidateText.match(regex) || [];

  for (const token of extractedTokens) {
    const normalized = normalizeToken(token);
    if (!factBlock.indexedTokens.has(normalized)) {
      // Grounding Violation: Number generated by model was NOT in Fact Block!
      console.error(`Grounding violation detected: Token '${token}' missing from Fact Block.`);
      return false; // Blocks output; triggers fallback template
    }
  }
  return true;
}
06

Deterministic Mathematical Formulations

1. Indicative JEE Main Rank Normalisation: Given registered candidates $N_{\text{total}} = 14,50,000$ and student percentile $P$:

export function computeIndicativeRank(percentile: number): number {
  const TOTAL_CANDIDATES = 1450000;
  return Math.floor((100 - percentile) * (TOTAL_CANDIDATES / 100)) + 1;
}

2. Prudent Education Loan Borrowing Ceiling: Under Indian banking guidelines, prudent unsecured credit is capped at $4\times$ gross annual household income:

export function computeMaxPrudentLoan(annualIncome: number): {
  maxPrudentLoan: number;
  requiresCollateral: boolean;
} {
  return {
    maxPrudentLoan: annualIncome * 4,
    requiresCollateral: annualIncome * 4 > 750000 // Loans above 7.5L require property collateral
  };
}

3. Downside Monthly EMI Amortisation Model: Simulating downside risk on an ₹18L principal over 84 months (7 years) at a benchmark 10.5% interest rate:

export function calculateMonthlyEMI(principal: number, annualRate: number = 10.5, tenureMonths: number = 84): number {
  const monthlyRate = (annualRate / 100) / 12; // 0.00875
  const emi = principal * monthlyRate * Math.pow(1 + monthlyRate, tenureMonths) / 
              (Math.pow(1 + monthlyRate, tenureMonths) - 1);
  return Math.round(emi); // ~₹30,360/month on ₹18L loan
}

Database Schema Specification (Supabase / PostgreSQL)

CREATE SCHEMA IF NOT EXISTS wa;
CREATE EXTENSION IF NOT EXISTS vector WITH SCHEMA public;

-- 1. Session state ledger
CREATE TABLE wa.wa_conversations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    wa_id VARCHAR(32) NOT NULL UNIQUE, -- E.164 phone identifier (e.g. '919876543210')
    current_stage VARCHAR(32) NOT NULL DEFAULT 'STAGE_1_STABILISE',
    stage_depth_reached INTEGER NOT NULL DEFAULT 1,
    last_inbound_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    last_outbound_at TIMESTAMPTZ,
    advised_against_spending BOOLEAN NOT NULL DEFAULT FALSE,
    distress_flagged BOOLEAN NOT NULL DEFAULT FALSE,
    opt_out BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_wa_conv_wa_id ON wa.wa_conversations(wa_id);
CREATE INDEX idx_wa_conv_stage ON wa.wa_conversations(current_stage);

-- 2. Aspirant profile attributes
CREATE TABLE wa.wa_student_profiles (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    conversation_id UUID NOT NULL REFERENCES wa.wa_conversations(id) ON DELETE CASCADE,
    jee_percentile NUMERIC(5, 2),
    indicative_rank INTEGER,
    board_percentage NUMERIC(5, 2),
    home_state VARCHAR(64),
    annual_family_income NUMERIC(12, 2),
    stated_budget_limit NUMERIC(12, 2),
    career_aspiration VARCHAR(32) DEFAULT 'UNDECIDED',
    loan_test_completed BOOLEAN NOT NULL DEFAULT FALSE,
    downside_test_completed BOOLEAN NOT NULL DEFAULT FALSE,
    degree_test_completed BOOLEAN NOT NULL DEFAULT FALSE,
    loan_affordability_cleared BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 3. Inbound & outbound message ledger
CREATE TABLE wa.wa_messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    conversation_id UUID NOT NULL REFERENCES wa.wa_conversations(id) ON DELETE CASCADE,
    wamid VARCHAR(128) UNIQUE,
    direction VARCHAR(8) NOT NULL CHECK (direction IN ('INBOUND', 'OUTBOUND')),
    stage_at_transmission VARCHAR(32) NOT NULL,
    raw_content TEXT NOT NULL,
    tokens_prompt INTEGER DEFAULT 0,
    tokens_completion INTEGER DEFAULT 0,
    estimated_cost_inr NUMERIC(8, 4) DEFAULT 0.0000,
    grounding_passed BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 4. Verified institutional facts
CREATE TABLE wa.wa_college_facts (
    slug VARCHAR(64) PRIMARY KEY,
    display_name VARCHAR(128) NOT NULL,
    fee_min_inr NUMERIC(12, 2) NOT NULL,
    fee_max_inr NUMERIC(12, 2) NOT NULL,
    degree_awarding_institution VARCHAR(128) NOT NULL,
    ugc_status_clarification VARCHAR(255) NOT NULL,
    verified_rating NUMERIC(3, 2) DEFAULT 0.00,
    review_count INTEGER DEFAULT 0,
    primary_caution TEXT NOT NULL,
    data_verified_at DATE NOT NULL DEFAULT CURRENT_DATE
);

-- 5. Semantic review chunks (RAG)
CREATE TABLE wa.wa_review_embeddings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    college_slug VARCHAR(64) NOT NULL REFERENCES wa.wa_college_facts(slug) ON DELETE CASCADE,
    review_chunk TEXT NOT NULL,
    sentiment_rating INTEGER CHECK (sentiment_rating BETWEEN 1 AND 5),
    embedding public.vector(768), -- Gemini / text-embedding-004
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_wa_reviews_hnsw ON wa.wa_review_embeddings 
USING hnsw (embedding public.vector_cosine_ops);

Hinglish Crisis Safety Protocol & Tele-MANAS

Western toxicity models fail to identify Indian exam-stress idioms (e.g., "papa ka sapna tod diya maine", "kis muh se ghar jau"). The system deploys a decomposed 5-boolean classifier with zero tolerance for false negatives.
